# PI3_2026Q4 · Actividad 3: Transformación, Enriquecimiento y Respuestas de Negocio

Análisis de precios de oferta por metro cuadrado de **casas vs apartamentos** en 38 ciudades de Colombia (2026).

**Dataset:** [aptologia/casa-vs-apartamento-precio-m2-ciudades-colombia-2026](https://huggingface.co/datasets/aptologia/casa-vs-apartamento-precio-m2-ciudades-colombia-2026)  
**Fuente:** Aptología | **Licencia:** CC BY 4.0

---

## Objetivo de la entrega

- Cargar el dataset desde Hugging Face
- Aplicar controles de calidad
- Enriquecer el DataFrame con variables derivadas
- Responder las 5 preguntas de negocio de AE3 y AE2
- Documentar transformaciones, justificaciones y limitaciones
- Exportar datos finales y generar reporte descriptivo `.txt` de forma automática
